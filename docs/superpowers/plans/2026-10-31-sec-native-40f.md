# SEC fund eligibility and native 40-F Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Exclude fund vehicles from corporate financial ingestion and restore BMM/NICM annual structured financials from original SEC 40-F XBRL.

**Architecture:** Use the existing OpenFIGI operating-security rule before queue limits/resume. A narrowly scoped companyfacts-404 fallback selects the latest 40-F independently of noisy 6-K traffic, discovers its extracted XBRL from the SEC directory, validates issuer/IFRS/CAD context, and writes native annual periods to a separate table. Native values never enter the legacy USD financial/valuation tables; journal and publication fingerprints include the restored coverage.

**Tech Stack:** TypeScript, fast-xml-parser, Supabase/Postgres, existing tsx behavior checks.

**Spec:** User request dated 2026-10-31 and `../../sec-native-40f.md`.

## Global Constraints

- Sources rechecked 2026-10-31; retain original currency, accession, filing date, concept/context/unit and source URL.
- Four audited funds: SPY/DIA/MDY (ETP), SWZ (Closed-End Fund). Unknown security types, operating companies, REITs and ADRs remain eligible.
- BMM CIK 0001732379 and NICM CIK 0001526475 only; IFRS/CAD annual source periods, missing values stay null.
- No currency conversion, ADR-ratio enrichment, quarterly inference, USD valuation activation, production migration execution or PR merge in this task.
- Review passed => push feature branch and create PR targeting db-foundation.

## Review Focus

- Security eligibility pages after row 1000 and query failure must not silently reintroduce funds.
- 6-K traffic must not hide the latest annual filing.
- 403/500/transport failures must remain failures; fallback only on companyfacts 404 for audited issuer identities.
- Wrong CIK, taxonomy, unit, dimensions, nil or conflicting facts must never become consolidated CAD values.
- Native write failure must not produce a successful resumable journal or USD financial writes.
