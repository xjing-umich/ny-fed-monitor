# i18n 格式化层实施计划

> **For agentic workers:** 使用 superpowers:executing-plans 在本会话继续执行；用户已同意实施，并于 2026-10-29 确认中文金额采用亿/万美元。

**Goal:** 中文显示本地金额、股数、季度与日期，英文保持美国格式，同一数字在服务端和浏览器稳定一致。

**Architecture:** `web/src/lib/i18n/format.ts` 集中纯函数；现有 formatUSD / quarterLabel 保留兼容薄包装。调用点显式传 lang，表格金额不重复币种但表头注明美元；结构化数据原始数字和 ISO 日期不改。

**Tech Stack:** TypeScript；原生 Intl，固定 zh-CN / en-US、UTC；不增加依赖。

**Spec:** `web/docs/i18n-audit/round2/README.md` §3，用户确认的金额规则。

## Global Constraints

- 中文正文金额 `1.62亿美元`，表格 `1.62亿` + 美元表头；英文 `$162M`，最多 3 位有效数字。
- 现价始终保留 2 位小数，每股估值 ≥10 取整、<10 保留 2 位。
- 中文季度标签 `2026Q2`，英文 `Q2 2026`；中文正文日期年月日，密集表格可保留 ISO。
- 负号 U+2212；极小正占比显示 `<0.1%`；无效数字显示 `—`，无效日期保留原串。
- 不改变估值、持仓、排序和来源日期；不改机器用途的 ISO 字段。
- 保留用户要求的提交/推送边界，本轮只实现与验证。
- 后续授权（2026-10-29）：用户要求 code review，无问题后提交、推送并创建 PR；不合并、不手动部署。

## Review Focus

- 正负金额在万/亿、K/M/B 边界正确进位，不出现 1000K。
- 真实零与缺失/非有限值分开，极小正持仓不伪装成 0。
- 日期跨系统时区不偏一天，无效日历日期不自动纠正。
- 英文单语 llms 与 SEC 解析内部季度逻辑保持兼容。
- 表格和卡片的金额单位自包含；JSON-LD 的数字/ISO 值不被本地化。
