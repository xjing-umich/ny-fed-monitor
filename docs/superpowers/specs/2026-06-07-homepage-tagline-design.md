# 首页价值主张标语 (Homepage Value-Prop Tagline) — 设计

- 日期: 2026-06-07
- 状态: 待用户确认
- 涉及分支: 实现时新拉分支(当前工作目录与并发会话共用 `feat/seo-geo-round2`,实现前再定分支)

## 1. 目标与背景

首页首屏「价值主张太弱」:新访客进来只有一行极淡的 dateline,不清楚这是什么站、能干什么。当前最大的标题是 h2「本季显著动向」,**全页没有可见的 `<h1>`**。

本设计在**不胖回 hero、不浪费已收窄的顶部留白**的前提下,加一句极简理念标语,讲清站点定位。

## 2. 决策(已与用户确认)

| 维度 | 决策 |
|---|---|
| 形式 | 极简一句话标语 |
| 角度 | 复利 / 价值投资理念 |
| 视觉分量 | 中等:display 衬线,比正文略大,克制但能被看见 |
| 布局 | 方案 A:标语置顶,作为首屏第一句话 |
| 语义 | 标语做成 `<h1>`(顺带补上缺失的 h1,利好 SEO/GEO) |

## 3. 布局(方案 A)

容器顶部(`pt-1 sm:pt-2`)之内,顺序改为:

```
与最有耐心的投资者同行 — 追踪 13F 持仓,理解复利。     ← 新增 <h1>(中等,display 衬线)
• 截至 2026-03-31 · 34 位投资者 · SEC 13F · 45 天延迟   ← 原 dateline <p>(不变)
本季显著动向 ……                                        ← 原内容(不变)
```

层次:身份(标语)→ 语境(dateline)→ 内容(动向)。标语视觉上小于 h2「本季显著动向」,作为安静的定位句,不与内容标题抢焦点。

## 4. 文案(文案 1)

- 中:**与最有耐心的投资者同行 — 追踪 13F 持仓,理解复利。**
- 英:**Walk with the most patient investors — track 13F holdings, understand compounding.**

破折号后半句(「追踪 13F 持仓,理解复利。」/「track 13F holdings, understand compounding.」)用次文字色,前半句用主文字色,形成轻微的主次。

## 5. 视觉规范

- 元素:`<h1>`,作为容器第一个子元素(在 dateline `<p>` 之前)。
- 字号/字体:`font-display text-lg sm:text-xl font-medium tracking-tight leading-snug`。
- 颜色:前半句 `text-[var(--tt-text)]`;破折号及后半句包一个 `<span className="text-[var(--tt-muted)]">`。
- 间距:dateline 由「容器第一个元素」变为标语之后,给它加 `mt-2.5 sm:mt-3`;其余区块间距不变(「本季显著动向」section 仍是 `mt-6`)。
- 暗/亮主题自适应(沿用 `--tt-*` 变量,无硬编码颜色)。
- 中英文都走现有的 `isZh ? "…" : "…"` 内联三元,无需新 i18n 机制。

## 6. 文件改动

| 文件 | 改动 |
|---|---|
| `web/src/app/[lang]/page.tsx` | 在容器内、dateline 之前插入 `<h1>` 标语;给 dateline `<p>` 加上 `mt-2.5 sm:mt-3` |

仅此一个文件、一个新增元素 + 一处间距微调。无新组件、无新依赖、无数据读取改动。

## 7. 与并发会话的协调

并发会话正在做 SEO/GEO(已合并 PR #13/#14,改过本文件加结构化数据)。新增 `<h1>` 与其方向一致但需避免冲突:

- 实现前 `git pull` / 看清本文件最新状态,基于最新版插入。
- 若届时他们已自行加了 h1,则改为复用/调整,不重复加。

## 8. 不做的 (YAGNI)

- 不加品牌 kicker 行(方案 B)、不加 masthead 分隔线(方案 C)。
- 不加副标题、不加三支柱说明、不加 CTA 按钮、不动其它区块。
- 不引入 i18n 库或新组件。

## 9. 验证(本项目无测试套件)

- `tsc` 通过。
- 起 v20 dev server(`localhost:3000`),用 Chrome 看 `/zh` 与 `/en`:
  - 标语在首屏第一行、中等分量、主次色正确。
  - dateline 紧随其后,间距自然;「本季显著动向」未被挤动。
  - 暗/亮主题、移动端(窄屏)下不换行错乱或溢出。
  - 确认 `<h1>` 仅一个(DOM 检查 `document.querySelectorAll('h1')`)。
