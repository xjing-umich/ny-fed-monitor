# Compounder 北斗星 · 1–2 年产品纲领

- 日期：2026-06-30
- 性质：**所有 PRD 之上的纲领**（非功能 spec）。`docs/superpowers/specs|plans/` 里的每个 PRD 都应能回答"它推进了哪根柱子 / 哪个阶段"。
- 视野：1–2 年愿景；近场第一段 = 0–6 个月。
- 锚定决策（2026-06-30 与用户确认）：终局 = **A 可持续权威内容站 + C 个人代表作**（营收只为覆盖成本，非做成生意）；节奏 = **B 推向低维护稳态 + C 阶段性高投入**。

---

## 1. 身份定位（一句话）

> **Compounder 是 GEO 时代关于"伟大投资者在买什么、它到底贵不贵"最可信、最可被引用的免费参考站——以保守价值投资思想（巴菲特 / 格雷厄姆 / 格林沃尔德）为护城河，不荐股、不喊目标价。它既是一份公共品，也是一件"独立做到极致"的作品。**

锚三件事：**可信**（权威）、**极致**（代表作）、**不荐股**（哲学护城河，同时是区别于满屏荐股站的信任资产）。

## 2. 操作信条（"把事做对"的可执行版）

每个 PRD 都要守：

1. **正确性 > 一切**：标来源 / as-of / 哪期财报；宁可"无法评估"也不输出可疑数字。
2. **不建议、不预测**：无 buy/sell/目标价/评级；只给事实、区间、安全边际、是否进击球区。
3. **人声、非 AI 腔**：路透电讯稿口吻；AI 生成内容必带免责且与事实分层。
4. **快且可达**：RSC / 零 hydration / 可被爬可被 AI 引；a11y 与性能是底线。
5. **自运转优先**：每个功能过一关——"作者消失两个月，它还能继续供应新鲜、正确的页面而不崩吗？"凡需人定期手动维护的，要么自动化、要么砍。
6. **英文优先、中文次之**：内容模板双语自动产出；**人工长文只写英文**，中文靠模板覆盖（守低维护）。

## 3. 四根柱子：当前态 → 目标态

| 柱子 | 当前态（2026-06-30） | 目标态（A+C） |
|---|---|---|
| ① 形式/产品 | 三腿（13F×估值×宏观），引导线已接；macro 仍孤岛 | 一条连贯旅程：任一深页都能走到"谁在买×值不值"合力；macro 去留见 §6 决策 |
| ② 流量 | SEO/GEO 押对，404 已修通收录解锁；程序化数百实体页 + /learn 常青 + 季度报告 + 多平台播种 | 被 AI 引擎引用（GEO）+ 描述性长尾稳定排名；域名权威随时间+外链复利 |
| ③ 留存 | 最弱；Newsletter 基建有但未发；无账号 | 轻留存：季度复盘 + 申报季 newsletter 真发；常青复访；**不建账号体系** |
| ④ 营收 | 故意后置；广告 publisher ID 备好 | 仅覆盖成本：达量开展示广告 / 轻"赞助·支持"入口。**不做付费墙/订阅** |

两个定调：
- **留存刻意轻量**：A+C 下账号/个性化/提醒是过度工程（违 YAGNI），靠 email + 常青 + 品牌复访即可。
- **营收封顶"覆盖成本"**：故"哲学↔营收"张力消解；真正张力转移到 **B+C 的"时间 vs 广度"**——solo + 低维护，不能什么都做。

## 4. 自运转骨架（B+C 命根）

**已过关（作者消失也照跑）✓** —— 数据层全程 cron：

| 管线 | 排程 | 作用 |
|---|---|---|
| `ingest.yml` | 每周一/四 | 13F 持仓入库（命脉，幂等） |
| `prices.yml` | 工作日收盘后 | 日更股价 |
| `valuation.yml` | 每日 | 重算估值快照 |
| `fundamentals.yml` | 每周六 | SEC 基本面 |
| `macro.yml` | 每日 | 宏观快照（页面读物化快照，构建期不实时抓外部 API） |
| `prices-cleanup.yml` | 每周日 | DB 体积清理 |

新季自动捕捉、价格自动更、估值自动重算、DB 自动瘦身 → 数据层通过"消失两个月"测试。

**唯一缺口 = 可观测性**（骨架在跑，但出事你不知道）：
- *静默失败*：cron 逻辑错误若 `exit 0` 不报警（活案例：`former_names` upsert bug，`.error` 未检查、仍打"upserted"，整户静默丢失多日）。
- *成本/配额悄涨*：流量起来后 Supabase egress / Vercel 用量可能越线；A+C 下"成本失控"是唯一能真正搞垮它的东西。
- → 补一层**轻量健康/告警**：管线失败、数据陈旧超阈、用量逼近配额时主动戳人。这是让它"配叫代表作、且作者能放手"的最后一块。

## 5. 发展路径（1–2 年，分阶段；"触达/权威"是持续后台轨）

**关键切分（化解 B+C 的内在矛盾）：**
- **机器（数据/页面）= 真自运转**：cron 全自动，消失两个月页面照样新鲜正确。
- **增长（内容/外链/社媒）= 本质靠人、阵发式**：不可自动化，但无妨——猛时集中产出，安静期里已发布的常青内容 + SEO 复利 + 自动数据继续替你涨。
- 故"低维护"修饰的是**产品**，不是**增长**。

**Phase 1 · 合力 + 可见**（0–6 月近场，大半在途）
- 发现面接力（已规划）+ 合并 `seo-geo-finish`（OG 卡 + AI-bot 放行）+ macro 决策落地（§6）
- 关键转化点补 `track()` 事件（出口点击 / newsletter 订阅）→ Vercel 后台可见漏斗
- **出关**：三腿连成一条路；招牌 CTA 已埋点；OG/AI-bot 上线

**Phase 2 · 韧性 + 权威**（0–6 月，部分并行）
- *韧性*：管线健康告警 + 成本/配额护栏（§4 那层）
- *权威*：GEO 可引用性核验/补全 + 季度共识报告当外链弹药 + 多平台播种 + **newsletter 真发起来**（8 月 Q2 申报窗）+ 英文常青文可持续节奏
- **出关**：AI 引擎开始引用；描述性长尾稳定排名；email 回访成形；放手数周仍自跑

**Phase 3 · 稳态 + 覆盖成本**（6–18 月，back half）
- ~2-3万 PV 开展示广告（仅覆盖成本）+ 定期正确性审计 + 低维护稳态
- **出关**：月级无人值守仍供新鲜正确页面；成本自付
- 注：营收是 1–2 年里程碑，**不是 6 个月目标**（新域名权威是限速器），且始终不当记分牌（见 §7）。

## 6. 明确不做（北斗星的另一半 = 说不）

solo 跨 1–2 年最大的敌人是 scope creep。钉死不做：
- 账号体系 / 登录
- 付费墙 / 订阅层
- 任何荐股 · 目标价 · 评级 · 买卖时机
- 手动中文长文（中文靠模板）
- 社区 / UGC / 评论
- 追逐每一个新平台（渠道按 ROI 选，不铺满）

**待决策（不默认假定）：macro 第三条腿的去留。** 低维护前提下该问它拉不拉得动自己的重量。三选一：(a) 用贴现率桥真正并入主线、(b) 剥成独立站（[[macro-standalone-demo]]）、(c) 冻结维持现状。**此为开放决策点，需专门拍板，不在本纲领默认。**

## 7. 度量（北极星**不是** PV）

A+C 下记分牌是**信任与手艺**：

**北极星（衡量"做对了"）**
1. 被 AI 引擎引用（手动查：问 ChatGPT/Perplexity"谁持有 X / X 贵不贵"会否引到本站）
2. 回访 / 被真人推荐（email 订阅 + 直接/回访流量，非一次性 SEO 过客）
3. 收录覆盖 + 长尾排名（GSC：索引页数、长尾位次）
4. 正确性零回退（数据完整性不出事——代表作的质量分）

**护栏/可持续指标（手段，非目标）**：PV、广告收入 vs 成本、Supabase/Vercel 用量 vs 配额、Core Web Vitals。

> **PV 和营收是"能不能活下去"，不是"做得对不对"的记分牌。** 防止被流量数字带偏。

## 8. 复盘节奏

- **季度复盘**贯穿 1–2 年：对照 §7 北极星看是否在轨、要不要调阶段。
- 首个检查点：~3 个月（约 2026-09）。

## 9. PRD 如何向纲领对齐

`prd-roadmap`（[[prd-roadmap]]）是"在做什么"的清单；本纲领是"要去哪"。每个新 PRD 开工前问一句：**它推进了 §3 哪根柱子 / §5 哪个阶段？** 答不上就别做（违 §6）。

- 可观测性层（管线告警 + 成本护栏）→ Phase 2 / §4 韧性。
- macro 去留 → §6 待决策。
