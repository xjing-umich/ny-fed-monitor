## 0. 背景与本文档定位

Compounder（复利）已定位为面向公开访客的财务内容站：「谁在买(13F) × 值不值(估值) × 大环境(宏观)」，AI 串成人话，免费、无账号、靠 SEO/GEO + 可分享卡片增长，中英双市场。域名已购买。Phase 0 骨架正在另一 session 重构。

本文档**只回答一个问题：冷启动的第一个楔子是什么、怎么做、怎么被看见**。不覆盖全站架构（见 product-direction）。

---

## 1. 楔子定义（已确认）

**第一个冷启动楔子 = 超级投资者持仓页（程序化、每位大佬一页）。**

理由：有现成搜索需求（"巴菲特最新持仓"）、用户已有 13F 数据、季度自然更新、可批量复制。

**赢过 Dataroma/WhaleWisdom/GuruFocus 的方式 = 三者组合（不公平优势叠加）：**
1. **中文优先** —— 老站全英文、中文几乎空白，先吃中文长尾（竞争低），站稳再扩英文。
2. **AI 叙述 / GEO** —— 把"为什么这么调仓、组合在讲什么故事"写成人话，赌被 ChatGPT/Perplexity 引用，而非和老站拼 Google 域名权重。
3. **估值叠加** —— 每个持仓旁带「贵/合理/便宜」判决，回答"我该不该跟"，是纯 13F 站没有的决策价值；用本环境内置的估值 skill（巴菲特/格林沃尔德/DCF/护城河）发力。

**核心理念：别人给"他买了什么"，你给"他买了什么 + 为什么 + 现在还值不值得跟"。**

**深 vs 广 = 少而精。** 先做 10-15 个最有搜索量的名家（Buffett/Burry/Ackman/Munger…），每页做到极致，用深度换 GEO 引用 + 口碑。重页面铺量会摊薄质量；GEO 时代 AI 更愿引用"有解释、有判断"的深内容。

## 2. 旗舰投资者页解剖（已确认）

以 `/zh/investors/warren-buffett` 为例，从上到下：

1. **顶部判决条（给人也给 AI）** — 一句话人话总结，同时作为 `<meta description>` 和 GEO 引用钩子。语气走"路透电讯稿"，不走"小助手"。
   - 例："伯克希尔本季减苹果 13%、增西方石油至第六大持仓。前十大持仓中 6 只判为'偏贵'，2 只'合理'。"
2. **本季动作（AI 叙述）** — 加/减/清/建仓，每个动作配一句"为什么调、组合在讲什么故事"。老站只给数字 delta，这是差异点。
3. **持仓表 × 估值叠加** — 每行：股票 / 占比 / 本季变化 / **「贵·合理·便宜」判决徽章**（点入个股估值页）+ 一行依据（如"P/E 34，高于十年均值"）。
4. **可分享卡片** — "判决条 + Top5 动作"渲染成图，带 compounder 水印 + 回链，转发即曝光。
5. **数据来源与日期** — SEC 13F 原始申报 + 申报日 + 快照日。满足全局硬规则"标注来源和日期"，也是 GEO 信任信号。

### 2.1 去"AI 味" + 诚实披露（已确认，两条同时成立）

**原则：AI 在后台干活，前台读起来像一个克制的财经编辑写的；但诚实披露这是 AI 生成、可能有错、不构成投资建议。**

- **语气**：数字先行，文字只连点。无"让我分析一下"、无 emoji、无"值得注意的是"等水词。判决用分析师口吻，不用"AI 认为"。AI 只在能被事实锚定处说话——无数据支撑的"故事性发挥"一律砍。
- **披露**：
  - AI 生成的叙述段 → 旁边一行小字注脚："本段由 AI 依据 SEC 13F 申报自动生成，可能存在错误，不构成投资建议。"（脚注/出处行的语气，非大红警告。）
  - 估值判决徽章 → 可点开依据 + "AI 辅助、仅供参考"说明。
  - 页脚统一免责声明 + 数据来源/日期。
  - **纯事实模块（SEC 数字、持仓表）不挂该注脚**——那是申报原文，挂了反显得数据不可信。**注脚只跟着"AI 写的字"走，事实与生成视觉分层。**

## 3. 排期：竖切优先（已确认）

**与现有路线图的冲突：** 老路线图横切（Phase 1 数据 → Phase 2 分析 → Phase 3 估值+SEO+分享卡）。但本楔子第一天就需要估值判决和分享卡，按老图楔子要等到 Phase 3 才完整，冷启动被推太晚。

**"少而精"解套：** 只做 10-15 名家，其持仓去重后是有限集合（约两三百只票）。无需 Phase 3 的"全市场估值引擎"，只需给这两三百只票跑出判决即可——工作量从无限变可控。

**决策 = 竖切一刀。** 不按 Phase 1→2→3 横推，而是只为这 15 位 + 其持仓，一次竖切穿过所有层：13F 数据 → AI 叙述 → 这批票的估值判决 → 页面 + 分享卡。**先让旗舰页完整上线**，拿真实流量反馈再决定往哪加。全市场估值引擎（Phase 3 原意）留到验证楔子有效后再扩。

Phase 1 的 13F 数据回填照做（反正要）；Phase 3 的"估值判决 + 分享卡"只针对这 15 人持仓提前拉进来，跳过全市场引擎。

## 4. 分发与指标：单线、慢走（已确认）

**节奏总纲：不堆、不抢跑，一步一步来，每步验证完再加下一步。**

**第 1 步（现在，只做这个）：** 15 个旗舰页真正上线 + 做成 GEO 可引用形态 + 带分享卡。不开 newsletter、不铺社区、不投放。先让"东西存在且可被引用"。
- 竖线先跑透 **1-2 个**旗舰页（13F→AI叙述→估值→分享卡），跑通再复制到其余 13 个。

**之后逐个加（每步独立验证，不提前做）：**
- 第 2 步：季度申报来时，手动发几条编辑贴，**先只挑一个渠道**试（X / Reddit / 雪球），看哪个有反应。
- 第 3 步：某渠道真有回链了，再考虑 newsletter（邮件订阅 ≠ 账号，无登录）这种留存口子。

**GEO 可引用形态要点：** 语义化标题、事实带日期带出处、结构化数据（FAQ schema）、判决条写成可直接摘录的一句话。

**指标（现阶段极简，只看两个）：**
- **Search Console 收录页数**（东西被搜索引擎看见没——点击前的先行指标）。
- **手动问 AI 引擎**（ChatGPT/Perplexity 问"巴菲特最近在买什么"，看有没有引到你——GEO 验证）。

**冷启动北极星：回头 + 被推荐的真人**（后续用订阅数 + GEO/回链流量代理），不是原始 PV。PV 易自欺。Newsletter 及其指标本阶段搁置（排后，非否决）。
