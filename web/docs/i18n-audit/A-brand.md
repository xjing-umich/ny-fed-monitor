# A-brand 文案审核：首页 / 导航外壳 / 关于 / 法律 / SEO·OG·分享·邮件

审核日期：2026-10-27。只读，未改任何源文件。行号以审核时源码为准。

## 1. 区域概况

整体印象：**英文比中文好一截，中文多处是“英文先写、中文跟译”的产物**。英文首页 H1（"72 investors. One quarter. Every position they just reported."）、About 开头（"We pull it into one place and make it readable, so the thinking is left to you."）、页脚订阅说明（"One email after each quarter's 13F deadline: what the superinvestors did."）和中文页脚“每季 13F 申报截止后一封，讲超级投资者这季动了什么。随时退订。”都是很好的风格锚点：具体、有数字、像人话。问题集中在三处高曝光位置：首屏副标题、SEO/OG/分享文案、导航标签。

最主要的 3 个问题模式：

1. **工程口径直接上了首屏和导航（Z2/E3）**：第一屏用户要读“按 CUSIP 逐票归并”“逐笔对齐第一性原理估值”“申报进行中 · 94 位中 41 位已交 · 11 月 16 日截止后切换”；导航里有“按价值带 / By value”；搜索框写着“指标”（这是 NY Fed 项目留下的，站里已经没有指标）。最典型的例子是 `HeroMasthead.tsx:20`「逐笔对齐第一性原理估值。」，“对齐”是互联网公司黑话，“第一性原理估值”全站没解释过，读者也不需要懂。
2. **同一个概念五六种叫法（X1）**：超级投资者 / 投资者 / 投资人 / 顶级投资者 / 机构 / 经理人 / 基金，英文是 superinvestors / Super investors / top investors / smart money / managers / funds；买卖动向叫增持 / 买 / 买入 / 新建仓，加上英文芯片 NEW/ADD/EXIT/TRIM。最典型的是季度邮件标题「Q3 2026 超级投资者共识报告：41 家机构这季动了什么」：前半句说“位”超级投资者，后半句换成“家”机构。
3. **对外分享面基本没本地化，模板拼出来的句子不通（X4/X3）**：中文页的默认 OG 卡，以及共识 / 买入 / 卖出三张 OG 卡，全是英文；分享文案直接塞 EDGAR 原始大写公司名（`APPLE INC`）；接口报错只有英文，中文用户也照样看到。最典型的例子是中文分享句「本季 APPLE INC 被 25 位顶级投资者同时持有，居共识首位。via @thecompounder」，被字句、裸公司名、“居共识首位”都挤在这一句里。

另有一个系统性排版问题：`about.ts`、`legal.ts`、`ContactModal`、`footer.ts` 的中文大量用半角 `,` `?` `!` `(` `:`，同一段里还和全角混用（如 `legal.ts:166`）。
