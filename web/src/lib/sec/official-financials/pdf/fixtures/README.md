# Source-derived original annual PDF fixtures

Fresh sources audited **2026-10-31 UTC**. Financial expected values were transcribed independently after inspecting complete rendered original pages; expected.json converts those printed monetary thousands mechanically to currency units. Parser/extractor output was not used to construct expected values.

- **OZK:** [FDIC110 corporate disclosure index](https://securitiesfilings.fdicconnect.fdic.gov/api/instflng/cert/110), latest original [filing11868 attachment1](https://securitiesfilings.fdicconnect.fdic.gov/api/instflng/11868/attachment/1), filing/event date2026-02-25, FY2025/FY2024. Original139pages, SHA256 `ffd741ae5ed996c3851fa82bafb56cf4f6b78e71303424ff166d935e3b2840eb`. Attachment upload timestamp2026-02-26T01:53:51Z differs from the day-only filing/event date. Consolidated BankOZK, cert110/EIN71-0130170; commonOZK and preferredOZKAP distinguished. USD thousands except EPS; weighted EPS shares reported in rounded thousands, converted to share units without claiming unrounded precision. Net income, signed NCI adjustment, preferred dividends and common-available earnings are separate; generic revenue and explicit parent-attributable profit are absent. Cash purchase outflows retain negative signs.
- **TRMLF:** [official reports feed](https://www.tourmalineoil.com/investors/financial-reports), latest [English audited FY2025 annual PDF](https://tourmaline.cdn.prismic.io/tourmaline/aaidt1xvIZEnjVXx_FinalQ42025MDAFinancialStatements.pdf), authorized2026-03-04 and first published2026-03-04T22:03:37+0000. CMS sort date2025-12-30 is not period/publication date. Original90pages, SHA256 `16c2e1132c1b3928745739c3f9bea7d015242c86e8fc12af68ce982960e72214`. IFRS/CAD thousands; shares/EPS scale1. Revenue is exact Note13 customer-contract revenue; missing total liabilities/owner earnings remain absent. Common shares issued use four alternating count/amount columns, separate from weighted EPS counts. Cash/current-debt dashes represent explicitly reported zero. Ordinary CUSIP89156V106 mapping is audited registry identity; the PDF does not print TRMLF/CUSIP and does not establish an ADR conversion.

`*-original-pages.pdf` contain only relevant original pages extracted without rasterizing; `*-page-map.json` maps packet pages back to actual original PDF1-based pages. Runtime parsers never use this fixture remapping. `*-pages.json` retain positioned-line text from the complete originals, with actual source page numbers. PDF packet SHA is intentionally different from the original document SHA; production provenance hashes the full downloaded original.

The runtime uses pinned unpdf1.7.0's bundled PDF.js5.6 serverless build, verified on Node20.20 (production Node22). More recent unpdf versions require newer Node runtimes. No native canvas, Poppler, OCR or LLM is used in production. All new observations remain original-currency annual data and valuation-ineligible; interim/TTM/FX/security conversion is outside this adapter.

`offset-negative-sign.pdf` is a synthetic real PDF regression: minus at y702, cash-purchase digits at y700. Unassociated numeric-sign/bracket rows fail closed rather than becoming positive amounts. The complete currently audited originals contain no such orphan rows; a future ambiguous layout requires explicit adapter validation.

Parser regressions also reject an OZK denominator changed from rounded thousand shares to actual shares (using the disclosed EPS as an independent consistency check), and require separate verified year headers for each TRMLF basic/diluted EPS subtable.
